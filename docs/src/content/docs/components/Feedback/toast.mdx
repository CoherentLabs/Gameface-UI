The `Toast` component is a notification element that displays brief messages to the user. 
It allows users to receive feedback about an operation or to display important information.

## Installation

Every component ships with the boilerplate. If you are working in your own project, add `Toast` with the [Gameface CLI](https://frontend-tools.coherent-labs.com/gameface-cli/getting-started/):

```bash
npx gameface-cli add Toast
```

The CLI pulls in whatever `Toast` depends on. To refresh an existing copy, [update it](/docs/getting-started/updating-components) instead.

## Usage

To include a toast in your UI, call the `createToast` function with the desired options and include the `Toaster` component in your JSX.

<CodePreviewGFUI>
```tsx
import useToast from '@components/Feedback/Toast/toast';

const App = () => {
    const [Toaster, createToast] = useToast();

    // Example of creating a toast
    const showToast = () => {
        createToast({
            body: () => <>This is a toast message</>,
            position: 'top-right', // Position of the toast on the screen
            timeout: 3000, // Duration in milliseconds before the toast disappears
        });
    };
    return (
        <>
            <button onClick={showToast}>Show Toast</button>
            <Toaster />
        </>
    );
};

```
</CodePreviewGFUI>

## API

### `useToast(options?: UseToastOptions)`
Returns `[Toaster, createToast]`.

| Option Name | Type | Default | Description |
|-------------|------|---------|-------------|
| `max` | `number \| Partial<Record<Position, number>>` | none | The most toasts shown at once per position. When a new toast goes over it, the oldest one at that position is removed (with its hide animation). A number applies to every position; an object sets it per position. |
| `hideTimeout` | `number` | `1000` | The longest time in milliseconds a toast waits for its hide animation before it is removed anyway. |

### `createToast(options: ToastOptions)`
Creates a new toast notification with the specified options. Returns `{ id, dismiss }`, so the toast can be removed later from outside its body.
#### Parameters
| Option Name | Type                | Default       | Description                                                                                  |
|-------------|---------------------|---------------|----------------------------------------------------------------------------------------------|
| `body`      | `string \| JSX.Element` | `""`          | The content of the toast message. Can be a string or JSX element.                            |
| `position`  | `'top-left' \| 'top-center' \| 'top-right' \| 'middle-left' \| 'middle-center' \| 'middle-right' \| 'bottom-left' \| 'bottom-center' \| 'bottom-right'`  | `'top-right'` | The position on the screen where the toast will appear.                                      |
| `timeout`   | `number`            | `0`           | Duration in milliseconds before the toast disappears. `0` makes the toast persistent.       |

#### Body Arguments

When defining the body function, you receive the following helpers:

| Argument | Type | Description |
|----------|------|-------------|
| `close` | `(children: JSX.Element) => JSX.Element` | A wrapper function that attaches a click-to-close listener to any element. |
| `progress` | `() => number` | A signal returning the time left, from `1` (just shown) to `0` (timed out). Always `1` for toasts without a timeout. |
| `dismiss` | `() => void` | A function to programmatically remove the toast from the UI. |

### `useToastItem()`
Called inside a toast's body, returns its toast:

| Member | Type | Description |
|--------|------|-------------|
| `onHide` | `(fn: () => Promise<void> \| void) => () => void` | Registers work that must finish before the toast is removed, such as a hide animation. Returns a function that unregisters it. |
| `leaving` | `() => boolean` | `true` while the toast is hiding. |
| `progress` | `() => number` | Same as the `progress` argument. |
| `dismiss` | `() => void` | Same as the `dismiss` argument. |

## Guide

### Adding a close button

To allow the user to close the toast manually you can include the `Close` button inside the `body`:

```tsx
import useToast from '@components/Feedback/Toast/toast';

const App = () => {
    const [Toaster, createToast] = useToast();

    // Example of creating a toast
    const showToast = () => {
        createToast({
            body: (close) => (
                <>
                    This is a toast message
                    {close(<button>Close</button>)}
                </>
            ),
            position: 'top-right', // Position of the toast on the screen
            timeout: 3000, // Duration in milliseconds before the toast disappears
        });
    };
    return (
        <>
            <button onClick={showToast}>Show Toast</button>
            <Toaster />
        </>
    );
};

export default App;
```

### Adding a progress bar

You can display a progress bar inside your toast by using the `progress` signal within the `body` function, together with the [`Progress.Bar`](/components/feedback/progress-bar/) component:

```tsx
import useToast from '@components/Feedback/Toast/toast';
import Progress from '@components/Feedback/Progress/Progress';

const App = () => {
    const [Toaster, createToast] = useToast();

    // Example of creating a toast
    const showToast = () => {
        createToast({
            body: (close, progress) => (
                <>
                    This is a toast message
                    <div style={{ width: '100%', height: '5px', background: '#ccc' }}>
                        <Progress.Bar progress={progress() * 100} />
                    </div>
                    {close(<button>Close</button>)}
                </>
            ),
            position: 'top-right', // Position of the toast on the screen
            timeout: 3000, // Duration in milliseconds before the toast disappears
        });
    };

    return (
        <>
            <button onClick={showToast}>Show Toast</button>
            <Toaster />
        </>
    );
};
export default App;
```

:::caution
If you try to use the `progress` signal outside the return of the `body` function, it will rerender the entire toast every time the progress updates, which can lead to performance issues.
:::

:::note
The `progress` signal counts the time left down from `1` to `0`, updating 20 times over the toast's lifetime so it doesn't harm performance. Multiply it by `100` for a percentage.

Before version 2.0.0 it counted up from `0` to `20`. To update code written for it, replace `progress() * 5` with `progress() * 100` (or `(1 - progress()) * 100` to keep a bar that fills up instead of emptying).
:::

### Limiting how many toasts are shown

Pass `max` to `useToast` to cap the toasts at each position. When a new toast goes over the limit, the oldest one is removed:

```tsx
// At most 3 toasts at every position
const [Toaster, createToast] = useToast({ max: 3 });

// Only the top-right corner is limited
const [Toaster, createToast] = useToast({ max: { 'top-right': 2 } });
```

### Adding exit animations

A toast that is removed (timed out, closed, dismissed or pushed out by `max`) first gets the `toast-leaving` class and `data-toast-state="leaving"` on its wrapper, and stays on screen until its hide animation ends.

With CSS, start an animation from the `toast-leaving` class. The toast is removed when the animation ends:

```css
.toast-leaving .my-toast {
    animation: fade-out 0.3s ease-in forwards;
}
```

From code, register the animation with `useToastItem().onHide` inside the body. The toast is removed when the returned promise resolves:

```tsx
import { useToastItem } from '@components/Feedback/Toast/toast';

const MyToast = () => {
    const toast = useToastItem();
    let ref!: HTMLDivElement;
    toast?.onHide(() => playHideAnimation(ref)); // returns a Promise

    return <div ref={ref}>Saved</div>;
};
```

A toast never waits longer than `hideTimeout` (1000 ms by default), so a broken animation can't leave it on screen.

### Adding entrance animations

You can add entrance animations to the toast by adding CSS classes to the `body` element:

```tsx
import useToast from '@components/Feedback/Toast/toast';

const App = () => {
    const [Toaster, createToast] = useToast();

    // Example of creating a toast
    const showToast = () => {
        createToast({
            body: (close) => (
                <div class="animate-fade-in">
                    This is a toast message
                    {close(<button>Close</button>)}
                </div>
            ),
            position: 'top-right', // Position of the toast on the screen
            timeout: 3000, // Duration in milliseconds before the toast disappears
        });
    };
    return (
        <>
            <button onClick={showToast}>Show Toast</button>
            <Toaster />
        </>
    );
};

export default App;
```

```css
@keyframes fade-in {
    from {
        opacity: 0;
        transform: translateY(-10px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.animate-fade-in {
    animation: fade-in 0.5s ease-out;
}
```

### Programmatic Closing

While the `close` wrapper is convenient for standard buttons, you may need to close a `toast` programmatically after an logic-heavy action (like starting a tutorial or responding to a gamepad event). 
The `dismiss` function allows you to trigger the removal logic directly without relying on DOM click events.

```tsx
import useToast from '@components/Feedback/Toast/toast';

const App = () => {
    const [Toaster, createToast] = useToast();

    const showToast = () => {
        createToast({
            body: (close, progress, dismiss) => (
                <div>
                    Proceed with Action?
                    <button onClick={() => {
                        // 1. Perform your logic
                        console.log("Action Triggered");
                        
                        // 2. Programmatically close the toast
                        dismiss();
                    }}>
                        Confirm
                    </button>
                    
                    {/* Fallback for simple UI closing */}
                    {close(<button>Cancel</button>)}
                </div>
            ),
            position: 'top-center',
            timeout: 0, // Persistent until dismissed
        });
    };

    return (
        <>
            <button onClick={showToast}>Trigger Complex Toast</button>
            <Toaster />
        </>
    );
};
```
